# 🛡️ CyberPulse Update Scanner

**CyberPulse Update Scanner** is a lightweight, open-source Windows tool that scans your installed updates and flags potential issues — before they flag you.

No fluff. No install drama. Just peace of mind.

---

## 🚀 Features

- ✅ Scans installed KB updates on launch or on demand
- 🧠 Automatically checks Reddit + BleepingComputer for issue reports
- ⚠️ Flags updates as:
  - ✅ Safe
  - ⚠️ Maybe Fucked
  - ❌ Absolutely Fucked
- 🪟 System tray integration (optional)
- 🔒 Works offline with no data collection
- 💻 Built for Windows 10 & 11 (x64)


---

## 🔧 Installation

1. Download and run `CyberPulseInstaller.exe`
2. Choose install location and shortcut options
3. Launches automatically after install

No command line required. No Python needed. Just double-click and go.

---

## 🧠 How It Works

CyberPulse queries trusted forums and security communities to detect trends, known issues, or complaints about recent KB patches. It’s like having a sysadmin friend who checks Reddit 24/7.

---

## 🛠 Tech Stack

- Python 3.13
- PyQt6
- PyInstaller
- BeautifulSoup4 + Requests
- Inno Setup (installer)
